# win-dev

Write-ups by Win on software engineering, AI agents and code quality.
Published with GitHub Pages.

## Structure

```
index.html                  Home page: list of write-ups
<slug>/index.html           Each write-up's interactive page
drafts/<slug>/article.md    dev.to version of the write-up
drafts/<slug>/linkedin-post.md  LinkedIn post text and video plan
```

## Adding a write-up

1. Create `<slug>/index.html` for the page.
2. Add drafts under `drafts/<slug>/`.
3. Add an entry to the list in `index.html`.
4. Commit and push. GitHub Pages updates within a minute or two.
